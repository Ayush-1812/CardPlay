Audit date: 29 September 2026. Local reference commit: `a5b6dc50741f4e656b0025819c3131080b22e843`.

**Current disposition:** no repository-authored art, code, music or prose is cleared for direct incorporation. No LICENSE/COPYING file or project license grant was found in the local checkout, README or package manifests. `private: true` is an npm publishing flag, not a license. Public availability alone does not grant reproduction rights; [GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) explains the distinction.

This is a reuse evidence register, not a conclusion that every asset is permanently unusable. Re-evaluate an asset when actual permission or its applicable upstream license is recorded.

## Software dependencies

Manifests and lockfiles were inspected, not installed. [dependency-license-evidence.csv](evidence/dependency-license-evidence.csv) records direct dependencies, version requests, npm-lock resolution where present and locally recorded license identifiers. Metadata is an audit lead, not a substitute for packaged license/NOTICE files or a complete transitive audit.

Client npm lock records MIT for React/React DOM, React Router, Zustand, Framer Motion, mobile-drag-drop, @web-kits/audio, web-haptics and most build dependencies; ISC for lucide-react; Apache-2.0 for TypeScript. QR packages added in manifests are absent from that npm lock. Server has a Bun lock, but no server npm lock; Hono/@types/bun/TypeScript server resolution is not certified by the CSV. Root concurrently is also recorded. Do not claim one lockfile represents every install path.

When implementing, choose one package manager, pin an actual dependency graph, inspect all shipped license/NOTICE files, generate transitive notices/SBOM and remove unused dependencies. None of those library licenses licenses the reference repository itself.
